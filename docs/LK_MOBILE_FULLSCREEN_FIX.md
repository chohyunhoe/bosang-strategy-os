# 모바일 검수와 전체 화면 전환 수정

기존 RC4 브랜치의 모바일 화면 수정과 실제 버튼을 이용하는 회귀 검증을 main에 분리 반영한다. RC4의 다른 파서·사건관리 변경은 포함하지 않는다.

- 모바일 메뉴는 제목 문자열보다 기존 data-section 식별자를 먼저 사용한다.
- 전체 화면 모드에서는 모바일 검수 라우터가 기존 검수 클릭을 가로채지 않는다. pointerdown과 click의 중복 처리도 제거한다.
- 모바일 홈은 내용이 같으면 버튼을 다시 생성하지 않는다. 모바일 카드의 표시와 인쇄 시 화면용 UI 숨김을 보완한다.
- 기존 전체 화면 테스트는 사용자가 누르는 전체 화면 버튼을 거쳐 실행한다. 강제 클릭이나 화면 요소 제거로 테스트를 우회하지 않는다.
- 기본 모바일 검수→전체 화면→모바일 복귀 경로는 별도 브라우저 시험으로 확인한다.

기존 루트 index.html, 데이터 키와 렌더 함수, Product v2 문서·결과회수 코드는 변경하지 않는다. 합성자료만 사용하며 유료 AI나 외부 자료 API를 호출하지 않는다.

출처: 동일 저장소 release/v1-rc3의 ea906c1fc9fc8bbfc8d2543e26658b7feb22de94에서 모바일 관련 파일만 재사용했다. 해당 브랜치의 이전 6837c2a 반응형 검증은 107개 통과·1개 건너뜀을 기록했다. 이 분리 적용의 최종 검증은 해당 PR의 CI 결과를 기준으로 한다.
