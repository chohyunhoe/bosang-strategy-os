# 보상전략 OS 평가서 해석 프로토콜 v0.1

## 1. 목적

보상전략 OS는 감정평가서 전체를 요약하는 시스템이 아니다. 사업 개요·추진경과 등 이미 확보된 기초정보를 반복 정리하지 않고, 공시지가기준법에 따른 가격 산정구조를 해석하여 실무상 필요한 비교관계를 추출한다.

핵심 분석대상은 다음 네 블록이다.

1. 비교표준지 선정
2. 비교표준지 ↔ 대상토지 개별요인 비교
3. 비교표준지 ↔ 비교사례 개별요인 비교
4. 그 밖의 요인 보정치 산정

평가명세표는 위 블록에서 추출된 구조를 최종 단가·평가액과 대조하는 검증자료로 사용한다.

---

## 2. 해석 순서

1. 감정평가서 전체 페이지의 구조와 표 머리글을 분석한다.
2. 표준지 선정 블록을 찾는다.
3. 표준지와 대상토지 간 개별요인 비교 블록을 찾는다.
4. 그 밖의 요인 보정치 산정에 사용된 비교사례를 찾는다.
5. 비교사례가 평가사례인지 거래사례인지 구분한다.
6. 표준지와 비교사례 간 개별요인 비교 블록을 찾는다.
7. 그 밖의 요인 보정치 산정표와 연결한다.
8. 평가명세표에서 대상토지 최종 단가와 평가액을 검증한다.
9. 표준지-대상토지 및 표준지-비교사례 비교군을 QGIS/VWorld 시각화 입력으로 전달한다.

페이지 번호, 지번, 일련번호, 평가법인명은 사전 고정값으로 사용하지 않는다. 모두 문서 해석 결과로 획득한다.

---

## 3. 페이지 역할

MVP의 페이지 역할은 다음 여섯 가지로 제한한다.

- `STANDARD_SELECTION`
- `SUBJECT_TO_STANDARD_FACTORS`
- `STANDARD_TO_CASE_FACTORS`
- `OTHER_FACTOR_CALCULATION`
- `LAND_APPRAISAL_SCHEDULE`
- `IRRELEVANT`

페이지 역할은 제목 하나로 판정하지 않고, 표 머리글·본문 키워드·수치 구조·앞뒤 페이지 관계를 함께 사용한다.

## 8. 평가명세표의 역할

평가명세표는 최초 탐색의 중심이 아니라 최종 검증 블록이다.

### 추출 필드

- 일련번호
- 소재지
- 지번
- 지목
- 면적
- 이용상황
- 지분 또는 평가대상면적
- 결정단가
- 평가액
- 비고
- 근거 페이지

### 검증 항목

- 대상토지 지번 매칭
- 산출근거에서 도출된 단가와 결정단가 대조
- 면적 × 지분 × 결정단가와 평가액 대조
- 동일 지번 복수 행·분할평가·일단지 여부 확인

특정 지번이나 일련번호는 페이지 탐색 조건이 아니라, 전체 평가명세표 추출 후 대상토지를 선택하는 후처리 조건으로 사용한다.

## 11. 검토 큐 기준

다음은 자동 확정하지 않는다.

- 문언과 개별요인 수치 불일치
- 비교대상 분자·분모 불명확
- 사례 유형 불명확
- 사례 지번 또는 현황 누락
- 동일 사례기호가 복수 사례를 지칭
- 표가 여러 페이지에 걸쳐 있고 행 연결이 불명확
- 평가명세 단가와 산출근거 단가 불일치
- 산식 검증 실패
- OCR 숫자 신뢰도가 낮음

## 12. 역산 감사 — 원문 추출과 분리된 추정

대상토지의 최종단가는 확인되지만 대상토지별 종합 개별요인 산식이 원문에
제시되지 않은 경우, 다음 산식으로 후보 표준지별 종합 개별요인을 역산할 수 있다.

`종합 개별요인 = 최종단가 ÷ (표준지 공시지가 × 시점수정 × 지역요인 × 그 밖의 요인)`

### 상태 구분

- `SOURCE_CONFIRMED`: 평가서 원문에서 직접 확인된 값
- `ARITHMETIC_DERIVED`: 원문값의 단순 산술 결과
- `REVERSE_INFERENCE`: 후보 표준지를 가정해 역산한 값
- `REVIEW_REQUIRED`: 실제 표준지 선정 또는 적용관계 확인 필요
- `NOT_IDENTIFIABLE`: 원문 없이 값 또는 세부구성을 식별할 수 없음

### 안전 규칙

- 역산 결과는 `verification.reverse_factor_audit`에 저장하고 원문 추출 필드를 덮어쓰지 않는다.
- 종합 개별요인을 가로·접근·환경·획지·행정·기타 6개 값으로 임의 분해하지 않는다.
- 후보가 복수이면 후보별 역산값을 모두 보존한다.
- 복수 평가법인의 동일 표준지 후보 값이 수렴하더라도 실제 선정 표준지로 확정하지 않는다.
- 법인 간 후보 순위는 역산값의 수렴도만 설명하며 감정평가 적정성이나 보상금 증액 가능성을 판정하지 않는다.
- 지역요인 등 원문 미확인값에 중립값을 사용할 경우 `ASSUMED_NEUTRAL`로 표시한다.

## 13. 골든케이스 운영 원칙

광명시흥 중앙·정해 평가서는 일반화 엔진의 회귀테스트 자료로만 사용한다.

다음 값은 활성 파서의 조건문이나 상수로 사용하지 않는다.

- 특정 사업명
- 특정 평가법인명
- 특정 지번
- 특정 일련번호
- 특정 면적
- 특정 페이지 번호
- 특정 결정단가
- 특정 평가액

검증값은 `fixtures/golden_cases/` 아래에서 기대결과로만 관리한다.

## 14. MVP 완료 기준

처음 보는 평가서에서 다음을 사전 페이지 정보 없이 수행해야 한다.

1. 비교표준지와 기준연도 추출
2. 표준지-대상토지 개별요인 비교 추출
3. 사례 유형·지번·현황 추출
4. 표준지-사례 개별요인 비교 추출
5. 그 밖의 요인 보정치 산정구조 추출 및 산식 검증
6. 평가명세표 최종 단가·평가액 검증
7. QGIS/VWorld 그래픽 입력 데이터 생성

이 기준을 만족하지 못하면 범용 평가서 해석 완료로 판정하지 않는다.
