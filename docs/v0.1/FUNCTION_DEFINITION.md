# 보상전략 OS v0.1 기능정의서

## 1. 목적

감정평가서 원문을 의견서 작성 가능한 검토자료로 전환하는 내부 실무 자동화 MVP를 정의한다.

## 2. 사용자

- 토지보상 실무 담당자
- 변호사 검토 지원자
- 감정평가서 분석 담당자

일반 소비자 대상 보상금 예측 서비스는 v0.1 범위가 아니다.

## 3. 핵심 워크플로

1. 평가서 업로드
2. 텍스트/OCR 추출 및 문서구조 해석
3. 의견서 필수정보 갈무리
4. 편입토지 공란 특성정보 VWorld 보강
5. 평가법인별 수치 비교
6. 지도 기반 위치·현황 비교
7. 쟁점 후보 도출
8. 주장문 초안 생성
9. 제출 전 리스크 검토

## 4. 기능 목록

### F01 평가서 등록

입력: PDF, 추출 텍스트, 구조화 JSON

출력:
- 평가서 식별 상태
- 추출 상태
- 검토 큐

완료기준:
- 사건 간 입력 혼입 없음
- 이전 비동기 작업의 새 사건 반영 차단
- 원본 파일 외부 저장 전제 없음

### F02 텍스트/OCR 추출

- PDF.js 텍스트층 우선 사용
- 필요한 페이지만 OCR 후보 생성
- OCR 결과는 `NEEDS_REVIEW`, `auto_confirmed:false`
- 전체 이미지 PDF나 예산 초과 상태는 자동확정하지 않음

### F03 편입토지 및 평가행 구조화

구조화 대상:
- 소재지
- 지목
- 면적
- 평가법인
- 비교표준지
- 공시지가
- 시점수정
- 지역요인
- 개별요인
- 그 밖의 요인
- 적용단가
- 평가액

모호한 연결은 확정하지 않고 검토 대상으로 남긴다.

### F04 비교표준지·사례 연결

- 편입토지↔비교표준지 연결
- 비교표준지↔거래/평가사례 연결
- PNU exact-one 및 출처 상태 검증
- 복수 후보 동점·불일치는 fail-closed

### F05 개별요인 검토

- 평가서 기재 누계 보존
- 세부요인 출처 보존
- 법인별 차이 비교
- 역산값은 `REVERSE_INFERENCE`로 별도 표시
- 역산값으로 원문 세부요인을 생성하거나 대체하지 않음

### F06 그 밖의 요인 검토

표시 대상:
- 사례단가
- 시점수정
- 개별요인
- 사례기준/공시지가기준
- 격차율
- 결정치

자동으로 적정 보정치를 확정하지 않는다.

### F07 VWorld 공란 보강

보강 대상 예시:
- 도로접면
- 형상
- 지세
- 이용상황
- 용도지역
- 면적
- 지목
- 공시지가

원칙:
- 평가서값 자동 덮어쓰기 금지
- 기준연도와 출처 구분
- PNU 누락/복수 일치는 수동 fallback
- API Key 저장 금지

### F08 평가법인별 수치 비교

필지별로 다음을 비교한다.
- 비교표준지
- 개별요인 누계
- 그 밖의 요인
- 적용단가
- 평가액

차이는 검토 단서이며 오류 또는 증액 가능성으로 자동 판정하지 않는다.

### F09 지도 검토

- 편입토지
- 비교표준지
- 거래/평가사례
- 도로접면·접근성
- 현황 비교

브라우저 지도는 검토용 미리보기일 수 있으며, 최종 QGIS 산출물은 별도 로컬 게이트로 검증한다.

### F10 쟁점 후보

입력:
- 원문 평가요소
- VWorld 보강자료
- 지도 비교
- 법인별 수치 차이

출력:
- 쟁점 후보
- 추가 확인자료
- 검토 우선순위

확정 법률판단 또는 감정평가 판단을 출력하지 않는다.

### F11 주장문 초안

쟁점 후보를 의견서 작업용 주장문으로 변환한다.

출력은 제출문이 아니라 수정·삭제·보완이 필요한 초안이다.

### F12 제출 리스크 검토

차단/경고 대상:
- 보상금 증액 단정
- 승소 가능성 단정
- 법률자문 확정 표현
- 감정평가 대체 표현
- 확인되지 않은 외부자료의 사실 단정
- 개인정보·회사기밀 노출

## 5. 비기능 요구사항

- 모바일·태블릿·데스크톱에서 검토 가능
- 원문·API Key·비밀번호 로컬 우선 처리
- 결정론적 회귀검증 가능한 데이터 구조
- 출처와 상태 추적 가능
- 실패 시 임의 보간보다 BLOCKED/REVIEW_REQUIRED 우선

## 6. v0.1 제외범위

- 보상금 예측
- 증액확률/승소확률
- 완전자동 법률자문
- 감정평가 대체
- 대규모 SaaS
- 개인정보 원문 클라우드 상시 저장
