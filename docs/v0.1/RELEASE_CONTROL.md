# 보상전략 OS v0.1 릴리즈 관제표

상태: `CHAT_IMPLEMENTATION_COMPLETE / LOCAL_GATE_PENDING`
기준일: 2026-08-17
기준 브랜치: `main`

## 1. 종료 결론

보상전략 OS v0.1은 신규 기능 개발 단계가 아니라 릴리즈 종료 단계로 전환한다.

v0.1의 제품 목표는 다음 한 문장으로 고정한다.

> 감정평가서 원문을 입력하면 의견서 작성에 필요한 평가요소를 구조화하고, 외부 공적자료와 지도·수치 비교를 검토 보조자료로 연결한 뒤 쟁점 후보와 주장문 초안을 생성하는 실무 자동화 MVP.

이 문서 이후 v0.1에는 신규 엔진, 신규 상태체계, 신규 프레임워크, 보상금 예측, 증액확률, 자동 법률판단 기능을 추가하지 않는다.

## 4. 반드시 유지할 안전 경계

- 자동 결과는 검토 보조자료이며 감정평가 판단을 대체하지 않는다.
- 보상금 증액 가능성·승소 가능성·적정 보상액을 자동 확정하지 않는다.
- 법률자문 확정 표현을 사용하지 않는다.
- VWorld/지도/OCR/역산 결과가 평가서 원문값을 자동 덮어쓰지 않는다.
- 실제 PDF·비밀번호·API Key·상세주소·PNU·회사 원자료를 저장소에 커밋하지 않는다.
- 모호한 후보, 복수 일치, 연결 실패는 사람 검토 또는 BLOCKED 상태로 남긴다.

## 6. 남은 로컬 전용 게이트

챗/GitHub에서 대체할 수 없는 항목만 남긴다.

### Gate A — 실제 PC 평가서 1건

`RUN_PC_GATE.cmd` 실행 후 익명화 실제 평가서 1건으로 다음을 확인한다.

- Parser 실행 및 평가서 1건 인식
- 편입토지·평가행·비교표준지 구조 완전성
- 수치 오추출/NaN/undefined 없음
- 자동확정 없음
- 모바일 폭/데스크톱 결과 정렬 이상 없음

판정: `PASS`, `PASS_WITH_WARNINGS`, `FAIL`

### Gate B — 실제 Windows/QGIS 출력

실제 Windows QGIS 환경과 로컬 지적원자료가 준비된 경우에만 수행한다.

- 대상 필지 exact-one 확인
- CRS/geometry 검증
- 지도 PDF/PNG/QGZ 출력
- 항공사진/경계/라벨/축척 육안 확인
- 개인정보·API Key 산출물 누출 없음

이 Gate가 실패하지 않는 한 이미 통과한 Parser·스키마·안전 경계를 다시 설계하지 않는다.
