# 보상전략 OS v0.1 리스크 체크리스트

## 1. 목적

v0.1을 실제 실무 검토 보조도구와 이직 포트폴리오로 사용할 때 발생할 수 있는 법률·감정평가·개인정보·데이터·기술 리스크를 종료 전 점검한다.

## 2. 감정평가 경계

- [x] 감정평가 업무를 대체한다고 표현하지 않음
- [x] 적정 보상액을 자동 산정·확정하지 않음
- [x] 그 밖의 요인 적정치를 자동 확정하지 않음
- [x] 역산값을 원문 개별요인으로 대체하지 않음
- [x] 복수 표준지/사례 후보를 임의 확정하지 않음
- [ ] 최신 PC 게이트에서 원문 수치 오추출 0건 확인

실패 시: 해당 값/연결을 `REVIEW_REQUIRED` 또는 `BLOCKED`로 유지한다.

- [x] 보상금 증액 가능성 단정 금지
- [x] 쟁점은 `쟁점 후보`로 표시
- [x] 주장문은 작업용 초안으로 표시
- [x] 최종 제출 전 전문가/담당자 검토 필요 명시
- [ ] 포트폴리오 공개본에서 실제 사건의 법률적 결론이 특정되지 않는지 최종 확인

## 12. v0.1 종료 판정

다음 세 조건을 만족하면 새 기능 추가 없이 종료한다.

1. 저장소 CI가 통과한다.
2. PC Gate A가 `PASS` 또는 경미한 UI 문제만 남은 `PASS_WITH_WARNINGS`다.
3. QGIS가 v0.1 필수 산출물이라면 Gate B를 통과하고, 그렇지 않다면 로컬 의존 기능으로 명시해 비차단 처리한다.

통과한 항목은 다시 설계하지 않는다.
