# BSO 현장 집중모드 표준지 현황 복원

작성일: 2026-11-26 · 기준: PR #42 커밋 `68f771f`

## 사용자 피드백
집중모드에서 정보량을 줄이더라도 **표준지의 도로접면, 형상, 고저(지세), 이용상황은 상담 즉시 확인**할 수 있어야 한다. 이 네 토지특성은 표준지 후보 비교의 핵심이고, 사용자에게 선택 후보의 상태를 숨기지 않는다.

## 구현
- ② 표준지비교에서 **선택한 표준지 후보와 대상 필지**의 토지특성 4개를 요약 카드로 바로 보여준다. `TRAIT_FIELDS`의 `land_use`(이용상황), `road_access`(도로접면), `shape`(형상), `elevation`(고저)만 표시한다.
- 값은 기존 `buildStdMatrix`에서만 읽으며 원문에 없으면 `미확인`, 명칭이 추정이면 `추정`, 코드만 있으면 `코드 XX(명칭 미확인)`으로 명시한다. 값을 새로 추정하거나 다른 후보의 명칭으로 대체하지 않는다.
- 후보 ①·②·③ 또는 지도의 표식을 선택하면 동일한 기존 선택 상태로 요약카드가 갱신된다. 후보별 원문 PNU·공시연도와 특성 판정 원리는 변경하지 않는다.
- 884px 펼침과 PC는 **후보 목록 → 필수 특성 4종 → 기존 5열 비교표**. 412px 커버 집중 ②는 **후보 목록 → 필수 특성 4종 → 후보 상세 → 지도** 순서로 배치해 필수 현황을 먼저 볼 수 있게 한다. 지도/SVG DOM과 4:3 좌표 체계는 보존한다.
- ‘전체 정보’ 버튼을 눌렀을 때 기존 5열(펼침·PC), 1:1 비교표(커버)와 출처 범례·검증문구가 그대로 나온다.
- 이 요약은 **비교표준지 확정 및 가격 우열 판단이 아니며** API 속성 텍스트와 공식 토지특성현황도 원문을 구분한다.
