# BSO 현장상담 Gemini UI 3단계: Fold8 풀폭·지도축소·PC 동시 대조
작성일: 2026-11-25 · 기준: PR #38 `d252d05`

## 구현 범위
- **Fold8 펼침 884px**: ② 표준지비교 탭에서만 지도(상단 콤팩트 4:3, 지도 도구 우측) + 폭 전체 5열 비교표를 표시한다. ①/③을 누르면 기존 지도 좌측/상담 우측 구조로 복귀한다.
- **Fold8 커버 412px**: ③ 상담·요약 탭 진입 시 항공영상과 SVG DOM을 제거하지 않고 시각적으로 접는다. 52px 지도 미니바와 44px 복원 버튼을 두며 ①/②로 이동 시 자동 복귀한다.
- **PC 1440px**: 지도 기본 콤팩트(약 290px 폭) + 5열 비교표 독립 스크롤 구성. 지도 크게/간단히 토글을 제공한다. 실제 지도·비교표 및 상담패널은 같은 화면에서 사용한다. 초기 sticky로 표 머리가 가려지는 문제를 재검증 중 발견하여 PC 지도 sticky를 해제하고 표 내부만 스크롤하도록 수정했다.
- **Fold8 화면 접기/펼치기**: viewport resize 시 전용 모드와 하단 Dock 버튼 레이아웃을 재동기화한다. 필지별 메모·쟁점·조회 결과는 유지한다.

## 불변성
- `core/*`, `field-map.js`, VWorld API·지적 도형·좌표계·인증·호출 예산·세목표 기준일·출처 판정·요약/인쇄 코드는 그대로 둔다.
- 원본 이미지와 SVG는 항상 동일한 4:3 화면 영역을 사용한다. 레이아웃 토글만으로 새 항공영상·표준지 API 조회가 발생하지 않는다.
- 미확인 데이터, 공식 지적선, 법적 주의문 및 토지특성 원문 확인 보류 상태는 변경하지 않는다.
- PR #35–38 및 Fold8 운영 4190, 기존 테스트 4191/4192, Tailscale·인증 설정은 동결한다.
