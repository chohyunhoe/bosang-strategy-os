작성일: 2026-11-25
기준: PR #40 `028987b3c25e07433c1d2a17cbf50b9318f34d2a`

## 사용자 요청
10002 FastFlow 화면의 기능·조작감은 유지하면서 반복되는 원문 근거·출처 주석의 시각적 과밀을 제거한다.

## 적용 항목
- **확인 사실**: 필지 제목 옆 반복 원문 미대조 배지를 줄이고, 기존 `originPending()`, `provLegend()`, 2025 고시 변동 가능성 설명을 `원문·출처 상세 보기` 안으로 이동. 내용/출처단계는 변경하지 않는다.
- **고시 기재값 공통 배지**: KPI와 확인사실의 여러 `RECEIVED` 배지만 CSS로 시각 압축. `ESTIMATED`, `UNVERIFIED`, `STATEMENT` 및 출처 DOM 속성, HTML 내부 데이터는 그대로 유지.
- **5열 표준지 비교**: 공통 출처를 짧게 표기, 4개 설명 문구를 `비교 기준·근거 N건 보기`로 접기. **개별공시지가/표준지공시지가가 서로 다른 지표이고 가격 우열을 판정할 수 없다는 짧은 경고는 상시 표시**.
- **하단 이용안내**: 사업별 일반 유의사항을 기본 접힌 `이용·출처 안내`로 이동하며 자료 자체는 보존.
- **인쇄**: 화면에서 접혀 있던 고시 원문 대조 상태와 일반 유의사항을 인쇄 직전 펼쳐 노출하고, 인쇄 후 직전 접힘 상태를 복원. 기존 공적자료 실조회 화면값의 인쇄 배제 기능 유지.

## 안전 경계
- 가격 산식, 표준지 후보 판정, 원본 세목표, PNU·좌표·GIS·VWorld 호출, API 한도, 인증·세션·로컬 브리지 및 토큰 변경 없음.
- 표준지별 `추정`, `상이`, `미확인`, `보류`, 날짜 불일치와 핵심 경고는 그대로 남긴다.
- 화면에서 일반 `기재·수신` 표시만 정돈했으며 새로운 검증 완료나 공적 효력은 표시하지 않음.
- 사용자의 4190 운영/4191~4194 시험 서버와 기존 PR들은 전부 동결. 신규 Draft PR만 작성하며 운영 배포·병합 금지.
