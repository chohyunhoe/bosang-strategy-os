# BSO 현장 집중모드 (2026-11-26)

## 목적
PR #41(`39eb7a0`)의 주석 접힘 정리 이후에도 Fold8 화면에 정보가 과밀하다는 사용자 평가를 반영한다. 단순한 주석 접기가 아닌 **기본 화면의 정보 구조와 동선 자체를 변경**한다. 자료 원본, 공적자료 조회 절차, 법률/감정평가 판단과 데이터 모델은 그대로 둔다.

## 변경 사항
- 기본값은 `간편 상담`(body `data-f-focus=1`). 화면 상단 `전체 정보`로 모든 기존 패널을 즉시 복원하고, `간편 상담`으로 돌아올 수 있다.
- **① 대상확인:** 필지명·공부면적·편입면적·편입률, 실제 중요 경고, 명시적 공적자료/지도 조회, 상세 정보 전환을 표시한다. 확인사실·표준지·상담 등은 동시에 늘어놓지 않는다.
- **② 표준지비교:** 지도와 표준지 비교 기능만 보여준다. Fold8 펼침에서 기존 PR #39의 풀폭 5열 표를 유지한다. 후보 선택/추정/미확인/기준연도/가격 우열 경고 보존.
- **③ 상담·요약:** 상담 메모를 우선 배치, 상담 쟁점과 확보할 문서·후속조치를 각각 기본 접힌 44px 펼침 영역에 둔다. 체크박스 선택 개수는 상시 표시. Fold8 커버에서는 기존 지도 미니바 동작 유지.
- **정보량 축소:** 상단 고시 전체 통계 배지·고객설명 모드·반복 출처 설명·KPI의 상세 상태 칩·기본 소유/면적 확인 폼은 간편 모드에서 숨기고, 전체 정보 모드에서 기존 DOM과 입력을 복원한다.
- **실질 위험 신호 상시 노출:** 고시 원문 미대조, 색인 밖 편입 미확인, 리 명칭 보완값, 면적 충돌, 일부 편입·잔여지, 소유관계 미확인, 지도 조회 후 지적경계 실패 등을 해당 사건 상태에서 별도 짧은 위험 태그로 표시한다. 공적 자료의 현재 확인 상태를 확정된 것으로 표현하지 않는다.
- **기존 작업 보존:** 다필지 선택·소유/면적 확인의 상세 입력, 검색·메모·쟁점·표준지 선택, 1인/묶음 현장 요약·파일 다운로드가 전체 정보 모드에서 계속 가능하다. 임의 자동 조회 없음.
- **인쇄 보존:** 출력 직전 전체 정보 레이아웃으로 복원하고 접혀 있던 주의사항·상담 쟁점·후속조치를 임시 펼쳐 인쇄, 인쇄 후 기존 간편모드/단계/접힘으로 되돌린다.

## 기술 범위 및 보호
- 변경 대상: `browser/consultation-sim/field.html`, `field.css`, `field.js` 및 E2E.
- 변경 금지: `core/*`, 지도 좌표·SVG·PNU 검증, VWorld/브리지 API 호출량, 감정평가 표준지 선정, 고시·도면 데이터, 인증·토큰·Tailscale 설정.
- 전체 정보 모드는 PR #41 이전 사용 흐름의 기능적 안전망이다.
- 운영 4190·기존 테스트 4191~4195와 PR #35~41은 동결. 새 브랜치와 신규 Draft PR만 허용한다.

## 검증 항목
- PC 1440 / Fold8 펼침 884 / 커버 412에서 초기 화면의 비표시 요소, 세 단계 전환과 지도·메모 및 브리지 동선, 리 이어받음·면적 충돌 등 위험 신호, 커버↔펼침, 출력 전후 상태 복원.
- 기존 전체 정보 모드와 법률·감정평가 출처 4단계, 후보 5열, 대용량 필지 묶음, 인쇄·파일 저장·메모/쟁점, 호출 수 보존 회귀.
- 사용자 Fold8 실제 조작감과 실제 VWorld 공적자료 정확성은 단위/E2E만으로 확정하지 않는다.
