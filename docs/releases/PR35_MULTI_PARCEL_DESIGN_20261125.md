## 2. MVP 범위(요청 4개만)
### ① 여러 필지 담기
- 검색창 옆 **'필지 추가'**. 현재 열린 필지(세목표 행 또는 색인 밖 조회)를 묶음에 담는다.
  - 첫 추가 때 `상담 묶음 #1`이 생긴다. 이름·연락처 입력란은 없다.
- **필지 키**
  - 세목표 행: `notice_id + serial`
  - 색인 밖: `PNU` 또는 정규화 주소
  - 같은 키는 추가를 막고 해당 필지로 전환한다.
- **PNU 확인 후 충돌 검사:** 공적자료로 PNU가 확인된 뒤 다른 슬롯과 PNU가 같으면 **'같은 PNU 중복 — 확인 필요'** 경고만 낸다. 자동 병합·삭제는 하지 않는다.
- **상한 10필지.** 소유관계 자동 매칭은 하지 않는다. 상담자가 담은 것만 묶는다.
- **필지별 소유 확인 상태(새 입력, 필지별)**
  - 확인 근거: `상담자 진술 / 서류 확인 / 미확인`(기본 미확인)
  - 공동소유 여부: `아님 / 공동소유(지분 미확인) / 공동소유(지분 서류 확인)`
  - 지분값은 **입력받지 않는다.** 계산에 쓰지 않으므로 받을 이유가 없다.

### ② 필지 전환 시 입력 보존
- **슬롯 = 현재 전역 9개 필드 + 소유 확인 상태 + 개별 메모.** 공통 메모는 묶음에 둔다.
- **전환 순서:** `saveSlot(현재)` → `loadSlot(대상)` → `st.epoch += 1` → `render()`.
  - 렌더 캐시 키 `lastMapKey`·`lastZoningKey`·`stdReviewKey`를 무효화한다.
- **늦은 응답 라우팅:** 조회 시작 때 `slotId`를 잡아 두고, 응답이 왔을 때 활성 필지가 아니면 **그 슬롯에 써 넣는다**(버리지 않음).
  - **적용 대상:** 공적자료(`pd`), 표준지(`std`), 용도지역 이력(`zoningExtra`). 셋 다 순수 데이터라 저장만 하면 된다.
  - **지도·지적 칸:** 비활성 슬롯에 도착하면 `LOADING` 칸을 '미조회'로 되돌리고 버린다. 다시 열 때 버튼으로 받는다.
  - 받은 칸(`cad.tiles`, `cad.features`)은 슬롯에 남아 **캐시가 유지된다.**
- **새 검색 결과 선택:** 활성이 묶음 필지면 먼저 저장하고, 새 필지는 '묶음 밖(미추가)' 상태로 연다. 묶음 필지는 그대로 남는다.
- **새 상담:** 묶음 전체를 비운다(지금과 같음).

### 2.1 필지별 독립 보존 항목(승인 조건 4)
슬롯은 아래를 **필지마다 따로** 가진다. 다른 필지 값으로 채우거나 덮어쓰지 않는다.

| 구분 | 보존 내용 | 출처 |
|---|---|---|
| 대상 필지 특성 | 지목·용도지역·**이용상황·도로접면·형상·고저**와 각 값의 기준연도·조회시각·출처·불일치 표시 | 슬롯 `pd.values`(공적자료 응답 원본) |
| 표준지 후보 | 표준지 응답 원본(`std.response`)과 후보별 **이용상황·도로접면·형상·고저**·용도지역·공시지가·공시연도·위치 확인 상태 | 슬롯 `std` |
| 후보 판정 | 그 필지의 검토 용도지역(사업 영향 배제 기준 포함)으로 다시 판정한 결과 | 슬롯 `std` + 슬롯 용도지역 — 판정 캐시 키에 **슬롯 ID**를 넣는다(현재 전역 `stdReviewKey`) |
| 검증 상태 | 용도지역 `verification_label`·상담자 확인값(관련성·근거 문서·확인자·**감정평가 기준시점**), 표준지 '감정평가사 선정 아님', 소유 확인 근거·공동소유 상태 | 슬롯 `zoningConfirm`·`zoningExtra`·소유 확인 |
| 상담 입력 | 개별 쟁점·기타 자유입력·개별 메모 | 슬롯 `issues`·`other`·`memo` |
| 지도 | 대상 경계·보기 모드·줌·지적 칸 캐시(`cad.tiles`·`cad.features`) | 슬롯 `map` |

- **통합 요약 표시:** 필지 특성은 필지별 줄에만 쓴다. 필지 간 특성을 합치거나 대표값을 고르지 않는다.
- **카드 규칙:** 공적자료 실조회 값(도로접면 등)은 기존처럼 카드 복사·저장에 넣지 않는다. 화면에서 필지별로 열람한다.

### 2.2 비동기 응답 혼선·조회 중 고착 방지(승인 조건 5)
- **요청 토큰:** 모든 조회는 시작할 때 `{slotId, op, token}`을 슬롯에 기록한다. 응답은 **같은 슬롯의 같은 토큰**일 때만 반영한다. 활성 필지·epoch로 판단하지 않는다.
  - 같은 슬롯에서 다시 누르면 토큰이 바뀌어 이전 응답은 무시된다.
- **반영 위치:** 활성 슬롯이면 화면을 갱신하고, 아니면 그 슬롯 데이터만 갱신한다. 다른 필지 화면에는 절대 쓰지 않는다.
- **고착 방지**
  - 슬롯마다 `busy` 상태를 조회 종류별로 둔다(공적자료·지도·지적·표준지·이력). 성공·실패·예외·폐기 어느 경우에도 `finally`에서 해제한다.
  - 브리지 응답이 오지 않으면 클라이언트 시간 제한(브리지 상한 120초 + 여유)으로 `TIMEOUT` 처리하고 '다시 조회'를 보인다.
  - **슬롯을 저장할 때 진행 중인 지도·지적 칸 요청은 `LOADING`을 '미조회'로 되돌린다.** 공적자료·표준지·이력 요청은 계속 진행하고, 응답이 오면 그 슬롯에 저장한다.
  - 새 상담·묶음 비우기는 모든 토큰을 무효화하고 busy를 해제한다.
- **표시:** 비활성 필지가 조회 중이면 필지 바 번호에 작은 '조회 중' 표시가 붙고, 끝나면 사라진다. 실패면 '실패' 표시가 남고 다시 누를 수 있다.

### ③ 전체 필지 지도 보기
- 지도 모드에 **'전체 필지'** 를 추가한다(묶음 2필지 이상일 때만). 기존 '필지 중심/후보 비교'는 선택 필지용으로 그대로 둔다.
- **그리는 것:** 지도를 이미 열어 대상 경계가 **exact-one으로 확인된 필지만** 번호 경계(①②③…)로 그린다.
  - 미조회·불일치·색인 밖 미확인 필지는 목록에 '위치 미확인'으로만 둔다. 추정 도형은 그리지 않는다.
- **호출:** 영상은 맞춤 화면 1장만 요청한다. 지적 칸은 자동 조회하지 않는다(기존 버튼·상한 그대로). 표준지 표식은 '전체 필지'에 그리지 않는다.
- **넓은 경우:** 필지들이 멀어 맞춤 줌이 12보다 작아지면 지도 대신 '필지 간 거리가 멀어 한 화면 표시 안 함'과 목록만 보인다.
- **필지 전환:** 번호를 누르면 그 필지로 전환한다(②의 전환과 같음).

### ④ 통합 상담요약
- **새 순수 함수 `buildBundleSummary`**(새 파일 `core/field-bundle.js`). 기존 `buildFieldCard`/`buildDirectCard`를 필지마다 호출해 재사용하고, 기존 카드 함수는 바꾸지 않는다.
- **'통합 현장요약 복사'(12~20줄)**
  - `상담 묶음 #1 · N필지 · 작성일`
  - 필지별 한 줄: `① 궁평리 320-1 · 답 · 공부 X㎡ · 편입 Y㎡(편입률 Z%) · 소유: 상담자 진술 · 공동소유(지분 미확인)`
  - **합계 규칙(합산 오류 방지)**
    - 같은 고시(`notice_no`)끼리만 합한다. 다른 고시·사업·기준일이 섞이면 고시별로 따로 보이고 **전체 합계는 내지 않는다.**
    - 합계 문구는 `고시 기재 공부면적 단순 합계 — 소유 지분 미반영 · N필지 중 M필지`로 쓴다.
    - 면적 값이 없는 필지(색인 밖 등)는 빼고, 빠진 필지 수를 적는다.
    - 공동소유·소유 미확인 필지가 하나라도 있으면 `⚠ 공동소유·지분 미확인 n필지 — 본인 몫 면적 아님`을 합계 바로 아래에 둔다.
    - **지분 반영 면적·금액, 묶음 전체 편입률, 보상액·증액·이주대책 판정은 만들지 않는다.** 편입률은 필지별로만 쓴다.
  - 공통 쟁점(여러 필지에서 고른 쟁점의 합집합 + 필지 번호)과 공통 후속조치(중복 제거), 미확인 총 n건.
  - 공통 메모는 요약에 넣는다. 개별 메모는 상세본에만 넣는다.
- **'필지별 상세 저장(.txt)':** 묶음 머리말 + 필지마다 기존 상세 검토본 `text`를 그대로 이어 붙인다. 고시·도면·법령·시점·미확인 전부 보존.
- **공적자료 실조회 값은 카드에 넣지 않는다.** 기존 규칙을 유지한다.

## 3. VWorld 호출 통제(일괄 조회 금지)
- 필지를 담아도 **아무 것도 자동 조회하지 않는다.** 공적자료·지도·표준지·이력은 모두 **선택된 필지**에서 상담자가 누를 때만 조회한다(지금과 같음).
- **상한을 묶음 단위로 올린다**
  - 지적 칸 호출 40회를 지도 객체별이 아니라 **묶음 전체 공유 카운터**로 바꾼다. 단일 필지에서는 지금과 같은 값이다.
  - 표준지 조회는 **묶음당 3회 상한**(약 450회)이다. 넘으면 버튼을 비활성화하고 '묶음 표준지 조회 한도'를 표시한다.
  - 상태줄에 '이번 상담 VWorld 호출 누계(지적 n · 표준지 n)'를 보인다.
- **캐시:** 필지 전환해도 슬롯의 `pd`·`map.cad`·`std` 응답을 재사용한다. 다시 열 때 재조회하지 않는다.
- **'전체 필지' 지도:** 영상 1장 외 추가 호출이 없다.

### 3.1 동일 조회 재사용·실제 호출량 통제(승인 조건 3)
- **묶음 응답 캐시:** 키는 `op + 정규화 요청값`이다. 예: `parcel_map|PNU`, `tiles|PNU|ix:iy`, `standard_lands|PNU|year|radius|review_zoning`, `vworld_land|PNU|year`.
  - 같은 키는 **어느 필지에서 불러도 네트워크 요청 없이** 저장된 응답을 쓴다. 성공 응답만 저장하고, 실패는 저장하지 않아 다시 누를 수 있다.
  - 표준지는 같은 PNU라도 연도·반경·검토 용도지역이 다르면 다른 키다. 판정만 다르면 재조회 없이 같은 응답으로 다시 판정한다(현재 방식).
  - **진행 중 요청 공유:** 같은 키 요청이 이미 진행 중이면 새 요청을 보내지 않고 그 결과를 기다린다.
- **상한(묶음 단위, 사용자 승인값)**
  - 표준지 조회: **묶음당 3회.** 캐시 적중은 세지 않는다.
  - 필지: **10개.**
  - 지적 칸: 묶음 공유 **40회.**
- **실제 호출량 계측**
  - 서버가 돌려주는 `request_count`(표준지·지적 칸)를 그대로 합산한다.
  - 상태줄과 '출처·검증 상세'에 `이번 상담 VWorld 호출 누계(지적 n · 표준지 n · 기타 n) · 캐시 재사용 n회`를 보인다.
  - 상한에 닿으면 버튼을 비활성화하고 사유를 표시한다. 자동 재시도는 없다.
- **보존 범위:** 캐시는 화면 메모리에만 두고 새 상담에서 지운다. 기기 저장·외부 전송은 없다(현재와 같음).

### E2E(PC 1440 · Fold 884 · Fold 412, 합성 색인·합성 브리지)
1. **단일 필지 회귀:** 기존 242건이 무수정으로 통과한다.
2. **담기·전환 보존:** A에서 쟁점 2개·메모·용도지역 확인값·기준시점 입력 → B 추가·입력 → A 복귀 시 전부 그대로.
3. **요청 경쟁**
   - A 공적자료 조회 중 B로 전환 → A 응답이 B 화면에 섞이지 않는다. A로 돌아가면 A 결과가 있고 **재조회 0회**다.
   - 같은 경우를 표준지·용도지역 이력에도 확인한다.
   - 지도·지적 칸은 전환하면 '미조회'로 되돌아가고, 고정 '조회 중'이 남지 않는다.
4. **호출 통제**
   - 10필지 담기 → 브리지 요청 0회.
   - 필지 전환 반복 → 추가 요청 0회(캐시).
   - 묶음 지적 40회 공유 상한, 표준지 묶음 3회 상한.
5. **전체 필지 지도**
   - exact-one 필지만 경계·번호로 그린다. 미조회·불일치 필지는 목록에 '위치 미확인'이다.
   - 영상 요청 1회. 번호 누르면 전환된다.
   - 먼 필지는 '한 화면 표시 안 함'.
   - 기존 대상 경계 좌표 정합은 유지된다.
6. **일부 색인 밖:** 세목표 2 + 색인 밖 1 → 합계 2필지만, 제외 1 표시.
7. **새 상담:** 묶음·슬롯·응답 캐시·호출 누계가 전부 초기화된다.
8. **Fold 412:** 필지 바가 한 줄(가로 스크롤)이고 가로 넘침 0. 지도+후보 3건은 기존처럼 첫 화면에 들어간다.
9. **특성 독립 보존(조건 4)**
   - A(도로접면 '세로(가)'·형상 '부정형'·고저 '저지'·이용상황 '답')와 B(다른 값)를 조회한 뒤 전환을 반복해도 각 필지 특성·후보별 특성·검증 상태가 섞이지 않는다.
   - A의 감정평가 기준시점만 바꾸면 A의 후보 판정만 바뀐다.
10. **동일 조회 재사용(조건 3)**
    - 같은 PNU 표준지를 두 번 눌러도 브리지 요청 1회이고 '캐시 재사용 1회'로 표시된다.
    - 진행 중 같은 키 요청은 1회만 나간다.
    - 실패한 조회는 캐시되지 않아 다시 누르면 요청한다.
    - 표준지 3회 상한(캐시 적중 제외)에서 버튼이 비활성화된다.
11. **고착 방지(조건 5)**
