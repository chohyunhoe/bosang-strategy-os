# BSO 바탕화면·시작 메뉴 진입

BSO는 저장소의 `RUN_BSO.cmd`로 내 PC의 로컬 서버와 화면을 자동으로 시작할 수 있다. 외부 웹사이트 주소를 직접 입력할 필요가 없다.

처음 한 번 저장소 폴더에서 `SETUP_BSO_SHORTCUTS.cmd`를 실행한다. 현재 사용자의 바탕화면과 시작 메뉴에 `BSO` 바로가기를 만든다. 다음부터는 바탕화면 아이콘을 더블클릭하거나 Windows 시작 검색에서 `BSO`를 실행한다.

바로가기는 기존 `RUN_BSO.cmd`를 호출한다. Node.js·선택적 Python 등 실행 환경 요건과 로컬 보안 점검, 127.0.0.1 전용 서버, 사건 JSON 저장 방식은 그대로다. 바로가기 설치 자체는 런타임 설치나 BSO 실행·자료 전송을 하지 않는다. 실행 창은 사용 중 열어 두며, 종료 전 사건을 저장한다.

현재 사용자 영역만 사용하며 관리자 권한, 로그인 시 자동 실행, 작업표시줄 강제 고정을 추가하지 않는다. 기존 BSO 관리 바로가기는 갱신하고, 같은 이름의 다른 바로가기는 덮어쓰지 않는다. OneDrive 등으로 이동된 바탕화면은 Windows의 사용자 바탕화면 위치를 따른다.

폴더를 옮긴 경우 옮긴 위치에서 설치기를 다시 실행해 관리 바로가기를 갱신한다. 삭제는 바탕화면 및 시작 메뉴의 BSO 바로가기만 지우면 된다. 프로그램·사건 파일은 삭제하지 않는다.

접근 경로가 간편해진 것이며 화면 렌더링에는 기존 브라우저를 사용한다. 독립 EXE 앱·PWA 설치·모바일 앱·직원 계정 동기화는 이번 변경에 포함하지 않는다. 업무용 PC 바탕화면 설치는 사용자 PC에서 최초 한 번 실행해야 한다.
