# 실행결과 본문 회수와 BSO 검토

## 변경

n8n Worker의 `Return LK Queue Result`는 기존 결과와 영수증을 유지하면서 `bso_result` 검토 패키지를 추가한다. `lk-bso-result/1.0`에는 본문, 문서·버전·산출물·입력·출력 지문과 실행번호, 승인 아님 표시만 담는다. 원래 지시문과 임의의 제공자 응답 필드는 내보내지 않는다.

패키지 생성은 작업 ID, 입력 해시, 출력 해시, Worker 실행번호와 기존 검증 통과 기록을 대조한다. 차단된 결과는 빈 본문만 허용한다. 패키지 생성 실패는 기존 Worker 결과를 지우지 않고 `bso_export_error`로 구분한다. 큐 메타데이터를 대조하는 것이며 제공자 전자서명 검증이나 법률 판단 승인을 뜻하지 않는다.

## BSO 사용

문서 진행관리의 `실행 기록 가져오기`에서 패키지 또는 한 건의 n8n JSON 결과를 선택한다. BSO는 본문 SHA-256을 다시 계산하고 저장된 문서·수정본·작업요청과 대조한다. 일치한 결과는 HTML 실행 없이 텍스트로 표시한다. 가져오기로 검수·승인·제출 상태를 올리지 않는다.

본문은 현재 사건의 현재 탭 메모리에서만 표시한다. 사건 백업에는 실행 영수증 메타데이터만 보관한다. 수정본 시작 시 이전 본문 표시를 숨긴다. 새로고침 후에는 원래 결과 파일을 다시 선택해 본문을 검증·표시할 수 있다. 기존 영수증과 모든 연결 필드가 일치해야 하며, 다시 열기로 영수증과 변경 이력을 중복 추가하지 않는다. 기존 본문 없는 영수증에 대응하는 결과 본문도 같은 방식으로 열 수 있다.

## 기존 큐 결과 변환

기존 Sheets 행 또는 n8n 결과 JSON을 패키지로 변환할 수 있다. 큐 행에는 `bso_receipt_json`과 결과·검증 메타데이터가 있어야 한다. 입력 파일과 같은 경로에 쓰거나 기존 파일을 덮어쓰지 않는다.

```sh
node scripts/export_bso_result.js PRIVATE_QUEUE_ROW.json NEW_BSO_RESULT.json
```

이 명령은 네트워크·모델 호출을 하지 않는다. 본문을 로그로 출력하지 않는다. 새 결과 형식을 배포하기 전의 원시 Worker JSON은 이 변환을 거쳐 본문을 가져온다.

## 검증 범위

합성 요청 → 접수 → 제공자 형식의 합성 테스트 데이터 → 결과 패키지 → BSO 가져오기를 결정론적 시험으로 검증한다. 실제 외부 AI가 실행한 결과라는 증거로 취급하지 않는다. 본문 변조, 오래된 수정본, 다른 작업·실행번호, 검증 누락, 패키지 버전 변경, 차단된 결과의 본문 유출, 중복 기록, 파일 덮어쓰기를 거부한다. 브라우저 시험은 HTML 비실행·변조 거부·백업 본문 미포함·백업 복원 후 재열기·수정 후 미리보기 제거를 확인한다.

유료 AI 실행, 실제 사건자료 전송, 자동 외부 발송은 이 개발 범위에 포함하지 않는다. 결과 JSON 회수는 수동 파일 가져오기이며 실시간 자동 동기화는 구현하지 않는다.
