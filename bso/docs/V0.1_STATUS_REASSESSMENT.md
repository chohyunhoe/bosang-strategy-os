# 보상전략 OS v0.1 상태 재판정

## 결론

현재 상태는 **구현됨 / PC 실사용 검증 전 / Draft 미병합**이다.

`구현됨`은 코드와 자동화 경로가 존재한다는 의미이고, `검증됨`은 실제 Windows QGIS 환경에서 원문·지도·최종 PDF를 육안 대조한 경우에만 사용한다. CI 통과는 회귀오류가 없다는 의미이며 추출 정확도나 지도 위치의 실사용 검증을 뜻하지 않는다.

## 상태 라벨

| 라벨 | 의미 | 현재 |
|---|---|---|
| 구현됨 | 코드·테스트·실행 경로 작성 | 주요 모듈 해당 |
| 검증됨 | 실제 사건자료와 PC 환경에서 결과 대조 완료 | 광명시흥 최종 그래픽은 미완료 |
| 병합됨 | 승인 후 기준 브랜치 반영 | 미병합 |

## 현재 사용 가능한 범위

- 감정평가서 기재값 구조화
- 공시지가·시점수정·지역요인·개별요인 추출
- 그 밖의 요인과 산정단가 **재계산 대조**
- 평가법인별 **수치 대조표** 생성
- 검토 후보 항목 정리

모든 결과는 담당자 육안검수를 전제로 한다.

## 지도 안전 게이트

연속지적도 ZIP을 사용하는 모든 사건은 PNU→SHP 검증을 통과해야 한다.

- PNU 검색 1건 강제
- 원본 JIBUN·행정구역 PNU 접두부·원본 CRS 대조
- EPSG:4326 변환좌표 범위 확인
- 사건별 필지 상호거리·방향 임계값 판정
- 입력 ZIP SHA-256 변경 시 기존 PASS 무효화
- 실패 시 검증 JSON 외 지도·중간 JSON·캐시·최종 PDF 전부 삭제
- PC 육안검수 전 지도와 최종 브리프에 DRAFT 표시

## 개인정보·외부통신 경계

원문 PDF와 성명은 로컬 처리한다. VWorld 위성지도 조회 시 원문이나 성명은 전송하지 않지만, 지도 범위에서 계산된 타일 좌표와 API 요청정보는 외부 서비스로 전송된다. 최종 브리프에는 원문 개인정보를 포함하지 않는 것을 기본값으로 한다.

## 고정 문구

> 본 자료는 감정평가서 기재값의 구조화 결과이며, 감정평가 판단을 대체하지 않습니다. 제출 전 전문가 검토가 필요합니다.

## 현재 남은 게이트

1. 광명시흥 Windows QGIS 그래픽 게이트 재실행
2. 실제 항공사진·필지 경계·표준지 위치 육안 대조
3. 칸샘플형 2페이지 PDF 최종 확인
4. 검증 완료 후에만 지도 상태를 VERIFIED로 변경
5. 별도 병합 승인 전 Draft PR 유지
