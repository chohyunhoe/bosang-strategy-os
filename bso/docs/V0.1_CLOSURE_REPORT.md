# 보상전략 OS v0.1 종료보고

## 1. 결론

보상전략 OS v0.1은 감정평가서 PDF를 입력해 비교표준지, 대상토지 개별요인, 비교사례, 그 밖의 요인, 평가명세를 구조화하고 법인별 비교표와 검토 큐를 생성하는 로컬 시용본으로 종료한다.

현재 단계의 목적은 감정평가 또는 법률판단을 자동 확정하는 것이 아니라, 평가서 검토 시간을 줄이고 사람이 확인해야 할 위치와 수치를 체계적으로 제시하는 것이다.

## 2. 완료 범위

- 텍스트 PDF와 이미지 PDF의 선택 OCR 처리
- 페이지 역할 분류 및 신뢰도 기록
- 비교표준지·기준연도·공시지가 추출
- 표준지↔대상토지 개별요인 비교 추출
- 평가사례·거래사례 유형 및 사례정보 추출
- 표준지↔사례 개별요인 비교 추출
- 그 밖의 요인 산식과 결정값 검토
- 평가명세 지번·면적·단가·평가액 추출 및 산식 검증
- 불확실값 REVIEW_REQUIRED 처리
- 동+지번 완성 전 GIS 입력 차단
- 복수 평가법인 비교 JSON 및 Markdown 보고서 생성
- Windows 원클릭 시용 배치 실행
- 광명시흥 2건과 익명시 샘플·예시 3건의 골든세트 운영

## 3. 시용 실행

```bat
RUN_TRIAL_BATCH.cmd "경일.pdf" "제일.pdf" "가람.pdf"
```

주요 출력:

- 법인별 canonical JSON
- batch_comparison.json
- trial_manifest.json
- trial_report.md
- trial-output.zip

## 4. v0.1 시용 가능 기준

- 필수 블록 6개 중 4개 이상 복원
- 표준지 또는 평가명세 핵심값 확인
- 불확실값 자동 확정 금지
- 검토 큐와 근거 페이지 제공
- 출력 JSON 스키마 검증
- 빠른 CI 통과

## 5. 확인된 한계

- 이미지 품질과 OCR 환경에 따라 추출률 변동
- 여러 페이지에 걸친 복잡한 표의 행·열 연결은 수동검토가 필요할 수 있음
- 사례 소재지·지번이 문서에서 생략된 경우 GIS 입력 불가
- QGIS 최종 지도 출력은 별도 로컬 에이전트 검증이 필요
- 의견서 문안과 쟁점 후보 자동생성은 v0.1 종료범위에서 제외

## 6. 안전 경계

- 보상금 증액 가능성을 단정하지 않음
- 법률자문 또는 감정평가 결과를 확정하지 않음
- 감정평가 업무를 대체하지 않음
- 개인정보 원문의 클라우드 저장을 전제하지 않음
- API 키와 원본 PDF를 저장소에 커밋하지 않음

## 7. 다음 버전 후보

v0.2에서는 신규 평가서 블라인드 테스트, OCR 캐시, QGIS 비교지도 연결, 검토 UI 연결을 우선 검토한다. 기능 확대 전 v0.1 시용 결과와 검토시간 절감 효과를 먼저 측정한다.
