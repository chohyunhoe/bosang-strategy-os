# Claude 교차검증 반영 결과

## 판정

Claude의 `조건부 부적합` 판정을 수용한다. 기존 브리프는 코드 작성 상태와 실사용 검증 상태를 구분하지 않아 과장 소지가 있었다.

## 수용한 지적

1. 상태 라벨을 `구현됨 / 검증됨 / 병합됨`으로 분리
2. CI 통과를 정확도 검증이 아닌 회귀오류 점검으로 한정
3. 연속지적도 ZIP을 쓰는 모든 사건에 검증 게이트 의무화
4. PNU 1건 확인 외에 JIBUN·행정코드·CRS·변환좌표 범위 대조 추가
5. 필지 상호거리·방향을 로그가 아닌 임계값 판정으로 변경
6. 실패 시 지도·중간 JSON·선택 geometry·타일 캐시·최종 PDF 전부 삭제
7. PC 육안검수 전 지도와 브리프에 DRAFT 표시
8. `산식 검증`을 `산식 재계산 대조`, `법인별 비교표`를 `법인별 수치 대조표`로 정정
9. VWorld 외부통신 범위와 최종 산출물 개인정보 제외 원칙 명시
10. 감정평가 판단 비대체·전문가 검토 필요 문구를 최종 브리프에 고정

## 현재 상태

- 구현됨: PDF 구조화, 수치 대조, 검토 후보 정리, QGIS 그래픽 파이프라인, 필지 검증 게이트
- 검증됨: CI 회귀테스트 통과 범위
- 미검증: 광명시흥 Windows QGIS 재실행 결과의 실제 항공사진·경계·최종 PDF 육안 대조
- 병합됨: 아님
- PR: Draft 유지
