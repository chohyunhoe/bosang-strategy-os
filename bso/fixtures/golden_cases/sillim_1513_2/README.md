# 신림동 1513-2 역산 감사 골든케이스

이 fixture는 동일 대상토지에 대한 프라임·라인 평가서의 원문 대조값으로
역산 감사와 법인 간 후보 수렴도를 회귀검증한다. 암호화 원문 PDF와 비밀번호는
개인정보·보안 경계상 저장소에 포함하지 않는다.

## 원문 대조 범위

- 프라임 PDF: 비교표준지 p.46, 감정평가사례 p.52, 기타요인 산식 p.63~65,
  1513-2 평가조서 p.93
- 라인 PDF: 비교표준지 p.26~27, 감정평가전례 p.37, 기타요인 산식 p.41~43,
  1513-2 평가조서 p.63

PDF 페이지 번호와 문서 인쇄면의 페이지 번호는 다를 수 있다.

## 검증 경계

- 원문확인: 대상면적, 최종단가, 평가액, 후보 표준지 공시지가, 시점수정,
  지역요인, 표준지별 기타요인
- 역산추정: 후보 표준지별 대상토지 종합 개별요인
- 원문확인: 1513-2의 실제 적용 비교표준지는 프라임 `처`, 라인 `K`인 신림동 1526-2
- 식별불가: 가로·접근·환경·획지·행정·기타 6개 세부 개별요인

`expected_reverse_audit.json`의 후보 `selection_status=REVIEW_REQUIRED`는 파서의
자동선정 방지용 증거층이다. 별도 `expected_e2e.json`은 원문에서 확인한 적용
표준지와 14개 핵심값을 신규 실행 결과와 대조한다. 두 fixture 모두 활성 파서의
조건문이나 상수로 사용할 수 없다.
