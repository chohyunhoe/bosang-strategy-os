# 익명시 샘플·예시지구 시용 골든세트

동일 대상토지(샘플동 301-4)를 경일·제일·가람 3개 평가법인이 평가한 이미지 PDF 세트다.

## 목적

- 광명시흥 전용 규칙을 깨는 두 번째 회귀세트
- 평가법인별 문서 길이·표 배치·사례 선택·개별요인 차이 검증
- 이미지 PDF의 선택 OCR 경로 검증
- 법인별 핵심 수치 비교표 시용

## 운용 원칙

- PDF 원문은 저장소에 커밋하지 않는다.
- `expected_values.json`은 수동 확인한 기대값 fixture다.
- 사업명·대상지번·페이지 번호·단가는 활성 파서 조건으로 사용하지 않는다.
- 신규 PDF는 먼저 범용 파서로 처리하고, 결과와 기대값의 차이만 회귀 실패로 기록한다.

## 시용 완료 기준

1. 3개 PDF에서 표준지·개별요인·그 밖의 요인·적용단가·평가액 후보를 생성한다.
2. 불확실한 값은 `REVIEW_REQUIRED`로 남긴다.
3. `run_batch_comparison.py`로 3개 법인 비교 JSON을 생성한다.
4. 평가서별 오류가 있어도 전체 배치가 중단되지 않는다.
