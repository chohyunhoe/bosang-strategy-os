개발자 옵션 — 원시 JSON·API·OCR 진단
본 도구는 감정평가서 검토 보조 도구입니다. 법률자문·감정평가 업무를 대체하지 않습니다. 보상금 증감을 단정하지 않습니다. 원본 문서는 현재 브라우저 세션에서 처리되며 앱 서버에 저장하지 않습니다. 단, VWorld 조회 시 PNU 등 조회 파라미터는 해당 API로 전송될 수 있습니다. 최종 판단은 전문가 확인 후 진행해야 합니다.

1. 평가서 등록

평가서 PDF 또는 JSON을 등록합니다. 추출 상태와 검수 우선순위를 확인한 뒤 다음 단계로 이동하세요.

2. 평가서 분석

평가서에서 편입토지·비교표준지·평가요소·수치 후보를 구조화하고 공적자료 보강 필요 항목을 표시합니다. 조회값은 확정값이 아니라 검토 보강자료입니다.

3. 지도 생성

GeoJSON 또는 로컬 QGIS 산출 미리보기를 불러와 대상토지·비교표준지·거래사례의 위치를 시각화합니다. 지도상 차이는 검토 단서이며 평가상 문제를 단정하지 않습니다.

4. 수치 표 생성

평가서에 기재된 법인별 공시지가·보정요인·단가·평가액 후보를 한 표로 정렬합니다. 표시된 수치는 검토 단서이며 보상금 증감을 단정하지 않습니다.

5. 결과 레이아웃 정렬

지도와 수치표를 데스크톱에서는 나란히, 모바일에서는 세로로 정렬해 최종 검토합니다. 기존 의견서 보조문안 검토는 개발자 상세 화면에서 유지하며, 제출 전 전문가 확인이 필요합니다.

원본 등록·추출 검수

감정평가서 PDF와 구조화 JSON 적용 상태를 확인합니다.

이미지 OCR·행단위 검수 작업대

원문·크롭 이미지·계산검산을 함께 확인해 OCR 후보를 검수 또는 보류합니다.

평가서 원본·추출상태

편입토지 기본정보

편입토지는 소재지와 지번을 분리하지 않고 parcel_address 기준으로 표시합니다.

공적 토지특성 보강

평가서 기재값과 브이월드 조회값을 분리해 대조합니다.

표준지·거래사례 통합

평가법인별 기호가 달라도 지번이 동일하면 하나의 표준지·거래사례로 묶어 표시합니다.

필지별 비교 보기

동일 필지에 대한 법인별 표준지, 개별요인 누계, 그 밖의 요인, 적용단가를 한 표에서 비교합니다.

편입토지↔표준지 개별요인

공적 API 보강 스펙과 평가서 기재 스펙을 나란히 비교합니다.

표준지↔거래사례 개별요인

표준지는 평가서 기재 스펙, 거래사례는 공적 API 보강 스펙 기준입니다. 지번쌍이 같으면 하나의 카드로 묶고 핵심 차이만 먼저 표시합니다.

그 밖의 요인 보정치

그 밖의 요인은 소수점 둘째자리로 표시합니다.

현장검토 자료

현재 사건에 이미 확보된 토지·공적자료·평가자료·지도 컨텍스트를 필지별로 모은 현장 확인 보조자료입니다. 새로 조회하거나 값을 추정하지 않으며, 없는 항목은 "미조회" 또는 "확인 필요"로 남습니다.

8. 산출물 센터

현재 사건 데이터로 만들 수 있는 산출물과, 아직 파일로 만들 수 없는 산출물을 있는 그대로 표시합니다. 미연결·생성불가 항목은 완료된 기능이 아닙니다. 생성된 문서는 전문가 검토 대상이며 감정평가 결과나 법률판단을 대체하지 않습니다.

검토 필요사항
